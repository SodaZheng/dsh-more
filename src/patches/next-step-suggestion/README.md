# 下一步输入建议

在当前会话回复结束、输入框为空时，用当前模型生成一句可选的下一步输入，显示为原生 placeholder。按 **Tab** 填入草稿并继续编辑；只有用户按 **Enter** 才会发送。**Escape** 可隐藏本次建议，**Shift+Tab** 保留原生焦点导航。

在「设置 → 插件 → 插件配置 → DSH More」切换「下一步输入建议」，实时生效。默认开启。每轮最多一次简短模型调用，同一上下文会合并并缓存请求；生成会消耗模型额度。没有明确下一步、网络失败或模型输出不合适时，保留原生输入提示。

- 沿用当前会话 provider/model，不需要额外密钥。输入限于首条和最近的可见用户/助手文本，最多 6 条，每条约 4000 字符，不包含工具结果、思考内容或运行时提示。
- 独立请求不执行工具、不写会话历史、不阻塞主任务。最多等待 30 秒；模型支持时关闭思考，否则采用模型声明的默认思考等级。
- 原生编辑器、附件和草稿持久化保持原有机制。仅在空草稿、无附件、无排队消息、非命令菜单且非中文输入法组合状态下接管普通 Tab；通过原生插入接口保留撤销能力。
- 切换会话、开始新一轮或关闭补丁后，不展示异步返回的旧建议；Host 在新一轮开始、Agent 卸载或补丁关闭时取消生成。缓存只在内存中，最多 100 个会话。
- 适配已安装的 DSH `0.2.1-rc.2` composer slot，保留原生注册身份、React.memo、依赖注入和子插槽。卸载后还原原组件；不修改共享平台层或用户设置文件。

测试覆盖生成输出、请求去重、历史隔离、过期响应、开关清理，以及 Tab、Enter、Shift+Tab、IME、草稿、附件和命令菜单交互。

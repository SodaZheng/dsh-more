# 独立任务

直接使用空白会话输入框上方的原生工作区选择器：

- 下拉菜单第一项为 **独立任务**，与已有工作区、**添加工作区…** 放在同一个菜单中；
- 已选择目录时，目录旁显示 **×**，点击即可清除本次目录选择并切换为独立任务；
- 切换后选择器显示 **独立任务**，下拉菜单同时显示选中标记；
- 不再添加侧栏或输入框旁的额外“新建独立任务”按钮。

点击原生 **新会话** 时跟随当前页面：独立任务中新建独立任务，项目会话中沿用当前项目；项目行上的新建操作优先使用明确指定的项目，不受当前页面影响。独立任务的新会话使用新的独立目录，原会话的历史、草稿和文件留在原处。当前来源尚未加载时保留页面并提示重试，不回退到最近使用的项目。重复点击只创建一次，失败可重试；创建期间切换页面或关闭补丁时不抢回焦点。

× 只改变当前空白任务的工作位置，不删除工作区或目录。项目转独立任务时，先创建原生会话并确认其输入就绪，再转移未发送文本和图片引用，最后打开目标会话。图片接收失败、目标草稿冲突或输入正在提交时拒绝切换并保留原草稿；创建期间用户切换到其他会话时，不抢回当前页面。独立任务转项目沿用 DSH 原生的工作区切换与草稿转移。

每个任务自动使用宿主机的 `~/Documents/DSH/tasks/task-<UUID>/`，由 DSH 原生会话创建 API 建立目录。不同任务互不共用目录；该目录不是临时目录，重启后可继续读写产物。任务不注册为 Workspace，在原生 **未分组 / Ungrouped** 列表中显示。原生列表只显示当前空白会话，发送消息后按普通会话保留。编辑、分支和消息重建沿用 DSH 的 cwd 继承语义。

同一个创建操作的重复点击只发起一次创建；请求失败后再次点击，使用原任务标识重试，避免响应丢失造成重复任务。关闭补丁会移除入口并恢复原生工作区门槛，已有会话及工作文件不会被删除。删除会话也不会删除任务产物目录。

底层 DSH `0.1.2-rc.1` 已允许 `session.create({ cwd })`；限制来自 Web 的工作区导航及空白输入框。此补丁面向 Web，不修改 CLI，也不创建 Git 仓库或虚构工作区。

实现全部位于本补丁目录。Host 的 `prepare` 仅校验 UUID 并返回宿主路径，不执行磁盘写入。Client 调用原生 `sessions.create`，保留模型选择、Agent preset、工具和权限机制。它只在会话已打开、工作区列表已加载、cwd 存在且会话不属于任何工作区时移除输入框的工作区门槛；业务 block、加载失败和普通项目会话继续使用原生限制。

`client/adapter.tsx` 和 `client/picker.tsx` 集中保存 RC 兼容代码：包装原生 Conversation 和 WorkspacePicker slot，保留原 registration、子 slot、store 及授权。独立选项只加入该菜单的局部展示投影，选择时由补丁截获，绝不写入 Workspace registry 或发送到原生工作区接口；因此原生菜单键盘操作、选中标记、添加目录流程继续有效。标签只修改原生 chip 的文本，并在关闭时恢复。低优先级空白备选注册使安装和卸载通过原生版本订阅触发重绘；卸载按身份恢复组件，不覆盖后续插件的替换。升级 DSH 后需复核这两个适配入口及 `_workspaceLabel` 标签定位。

`client/new-session.ts` 在显式注入 `uiWorkspace` 后包装公开的 `startSession()` 方法，统一处理侧栏、顶部与其他原生调用者的来源选择。只有独立来源走本补丁创建；明确项目、当前项目及没有选中会话时的默认入口继续调用原方法。关闭或卸载时按属性身份恢复，不覆盖后来安装的其他包装；子 Agent 页面按所属任务判断来源。

验证：`pnpm exec vitest run src/patches/projectless-tasks`，以及仓库 `pnpm run check` 和 `pnpm run package:check`。

自动化覆盖菜单局部选项、原生项目回调、×、标签恢复、草稿与图片交接失败保护、创建重试、独立启停与注册清理。已在隔离 DSH Web 验证下拉菜单选择独立任务、× 清除目录、选中标记，以及项目和独立任务双向切换保留未发送草稿；也验证了独立任务页面的侧栏和顶部新会话入口保持独立模式并创建不同目录，项目页面的新会话沿用当前项目。测试实例不配置模型密钥、不发送实际模型请求。使用已有安装时需重新构建、重启 DSH 并刷新浏览器。

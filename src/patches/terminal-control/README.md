# 对话控制终端

打开右侧终端，在终端顶部的「对话控制」中选择模式，再回到当前对话继续提要求。点击「怎么用」可以查看示例。例如「请在右侧终端执行 pwd，然后告诉我当前目录」。需要连续操作时可以说「请一直用右侧终端，先检查当前目录，再运行项目测试，把失败项告诉我」。助手每次调用终端工具，输入都会进入这个窗口现有的 shell 或前台程序。你可以看到原生终端实时输出，展开「最近操作」还能查看本窗口最近八次动作。

| 模式 | 读屏 | 输入 |
| --- | --- | --- |
| 关闭（初始状态） | 关闭本补丁的读屏工具 | 关闭本补丁的输入工具 |
| 受限控制 | 自动 | 展示完整单行命令，点击「允许这一次」才提交回车。可拒绝，60 秒后超时 |
| 完全控制 | 自动 | 直接发送命令、交互文本和按键，包括回车与 Ctrl+C |

命令以当前终端的系统权限运行。授权期间，当前对话的常规 Bash、PowerShell 和新建后台终端输入会被引导到可见侧栏。终端中的程序继续实时输出，助手可以再次读屏获取进度。操作记录中的「已发送」指输入进入终端；执行结果以终端输出为准。历史记录只在当前终端视图中保存，DSH 自身的会话工具记录按原有规则保存。

每个对话同一时间可授权一个终端。切换桌面、应用或浏览器标签时，只要当前窗口仍在运行，授权就继续绑定原终端。完全控制可以继续输入，受限命令仍需在 60 秒内确认。选择「关闭」、收起侧栏、切换到其他会话或移除原终端视图会撤销授权。连接异常时需重新选择模式。已经提交给前台程序的输入可能继续执行。DSH 自带的终端查看工具和人工键盘输入保留原有行为。

补丁复用 DSH More 的受信 API 和右侧终端使用的 xterm，按会话注册工具。未授权时没有轮询；授权后的请求由本地等待连接交付，屏幕只在实际操作时返回最近最多 40 行、4000 个 UTF-16 代码单元。受限命令在显示及提交前校验，控制字符、换行和 Unicode 格式控制符会被拒绝。过期或重复的请求不能再次提交。

自动化测试位于本目录的 `host.test.ts` 和 `client.test.ts`。桌面兼容性另外使用 DSH 0.2.2-rc.3、隔离的测试配置、Chromium 和真实 PTY 验证。

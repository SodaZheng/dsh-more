# 终端主机状态

在 DSH 右侧终端顶部显示运行 DSH Host 的机器的状态。通过「设置 → DSH More → 终端主机状态」开关，默认开启。

| 指标 | 含义 |
| --- | --- |
| CPU | 两次采样间所有逻辑核心的平均使用率 |
| 内存 | 已用物理内存（总量减系统报告的空闲量）/ 总物理内存 |
| 磁盘可用 | Host 用户主目录所在文件系统的可用空间 / 总空间 |
| 读、写 | 主机磁盘在采样间隔内的平均读取、写入字节数每秒 |

可见的终端共用一轮采样，约每两秒更新。关闭终端、隐藏页面或关闭补丁后停止轮询。CPU 和读写速率需要两次采样；系统未提供计数器时，对应指标显示「—」。通过浏览器远程连接或在终端内运行 SSH 时，指标始终来自 DSH Host。

磁盘 I/O 在 macOS 读取 IOKit 块设备统计，在 Linux 读取内核整盘计数器，在 Windows 读取物理磁盘性能计数器。
